# Agent instructions

## Commit messages

Never add attribution lines or trailers for AI tools to commit messages —
including "🤖 Generated with Codebuff", "Co-Authored-By: Codebuff ...", or any
similar footer, in any new commit, and never re-introduce them when rewriting,
rebasing or cherry-picking history. All commit messages are to look exactly as
if they were written by the human committer.

This applies now and to all future work in this repository.
